# 差异化矩阵 · PBC vs 家族样板

- 移植样板（client 链路底本）：`cervical-workbench`（`src/client.js` 482 行 → `lib/client.js` 488 行）
- 成熟对比基准：`breast-cancer-workbench` v0.12.0（**8 一级 / 27 二级**，26 号 §3 口径）
- 本仓：**9 一级 / 30 二级**（设置走顶栏，不占一级 —— 沿用基准 `UI-DESIGN.md:134`「配置不该占用一级注意力」）
- 对比日期：2026-10-25 · 证据等级：0 访谈（见 USER-RESEARCH），下列"特有表达"均为待验证假设

## 1. 一级重名率（实测，不是估计）

口径：与基准 8 个一级名**逐字**比较。

| 基准一级（8） | 本仓一级（9） | 逐字相同 |
| --- | --- | --- |
| 看板 | 看板 | ✅ |
| 病情整理 | 我的病底 | ✗（内容：抗体/纤维化/合并症，非"资料库+档案+汇总"） |
| 病情一图秀 | 生化线 | ✗（一图秀降为二级，见 §2 理由） |
| 临床 | 用药与应答 | ✗（内容：UDCA 剂量·依从·换线，非"治疗历程+试验+对照"） |
| 营养支持 | 痒与累 | ✗（症状线独立成一级，基准无对应一级） |
| 心理支持 | 并发症筛查 | ✗（骨骼/甲状腺/胃镜/维生素/肝影像） |
| 全程与康复 | 复查节奏 | ✗ |
| 收藏与回顾 | 报告与资料 | ✗ |
| — | 临床研究 | ✗ |

**重名率 = 1/9 = 11.1%**（阈值 ≤70%，26 号 §4.1）。二级顺序亦不同构（基准首个二级是"资料库"，
本仓是"今日概览"）。

> **防自欺声明**：本仓的低重名率不是靠改名得到的。8 个语义线仍对应 26 号 L1–L5/L8–L10（家族三层骨架的必然），
> 真正的差异在二级切法与字段：例如 L4「指标分析」在基准是"指标卡+趋势+分级"三件，在本仓是
> **"按这张单子的参考上限组织的指标卡 + 一图秀 + 分级说明"**，且第六条线「并发症筛查」在基准没有对应一级。
> 若只按名字判差异化，本表没有意义——评审时请对照 §3 的字段级差异。

## 2. 三条刻意不同（写清"为什么不同"，不是漏做）

| # | 与基准/样板的差异 | 为什么 |
| --- | --- | --- |
| D1 | **一图秀降为二级页**（基准是一级"病情一图秀"） | PBC 的指标同源（都出自同一张肝功能），一图秀只是 ALP/GGT/TBil 的另一种看法，不值得占一级注意力；基准把它独立，是因为乳腺有多条不同源指标（肿瘤标志物/血象/肝功） |
| D2 | **症状（痒与累）独立成一级** | 瘙痒与乏力是 PBC 的主要症状负担且**无客观检查替代**；塞进指标页会被读成备注。基准的"不适记录"在全程与康复内，因为是术后康复语境的附属 |
| D3 | **并发症筛查独立成一级，且按系统分节** | 骨骼/甲状腺/食管胃镜/维生素/肝影像各自独立来源、独立科室、独立节奏；合并成"随访"会丢失"谁开的、多久一次" |

## 4. S → F → A 同源表（场景 → 功能 → 验收）

| 场景 | 落到 (view, sub) | 验收断言 |
| --- | --- | --- |
| S01 ALP 箭头 | labs/指标卡 | 无 `ref_high` → 徽章「需参考上限」，且不出任何级别 |
| S02 控制住仍痒 | symptoms/我的记录 | 同日两列并置；只有一侧时不生成配对结论 |
| S03 夜间痒 | symptoms/影响与睡眠 | 夜间加重/抓痕/睡眠次数三字段可写可读 |
| S04 累到上不了班 | symptoms/今天的累 | 三档单选必选其一，自由描述可空（= `null` 不冒充空串） |
| S05 漏服 | treatment/当前用药 | 漏服 +1 可逆（更正而非删除），月视图计数 |
| S06 换二线 | treatment/换线记录 | 只存原文与日期，无任何判定列 |
| S07 骨密度 | screening/骨骼 | T 值原样存字符串，不解析等级 |
| S08 甲状腺 | screening/甲状腺 | 与主生化线不混算趋势 |
| S09 胃镜 | screening/食管胃镜 | 显示「距上次 N 个月」+ 参考间隔来源标注 |
| S10 多久查一次 | followup/节奏卡 | 零记录也能算出两个节点；带宽声明可见 |
| S11 门诊 8 分钟 | followup/就诊准备 → records/导出 | 勾选 5 条 → 导出文件非空且含截止日 |
| S12 相册里的单子 | records/导入 | 候选逐项确认；拒收后事实层零变化 |
| S13 找试验 | trials/检索 | 无结果显示该来源覆盖声明，不写"不存在" |
| S14 家人要不要查 | settings/关于 | 只有客观说明 + 问医生入口，无筛查功能 |
| S15 带给医生 | records/导出 | 私密项被过滤；文件可打开 |
| S16 半年变化 | dashboard/最近变化 | 三条结论位只并列事实，无好坏判断 |
