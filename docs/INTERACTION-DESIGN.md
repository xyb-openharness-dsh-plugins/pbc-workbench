# 小管宝 DuctPal 交互路径设计（INTERACTION-DESIGN）· 场景操作路径 + 录入双通道

> 判据来源：starter `docs/28-INTERACTION-PATH-DESIGN.md`（IP1–IP10）、`skills/hvt-requirement-review/references/interaction-path-consistency.md`（X1–X4）。
> 状态：**M1 产出，随 G1 同批签认**。签认前不开 HTML（IP1）；签认记录写 `docs/SIGNOFF-G1.md`。
> 版本：v0.1（2026-10-25）。路径变更**先改本文再改实现**。

## 一、总原则（本项目口径）

- **AI 协助默认**：说话 / 拍照 / 交 PDF → 结构化候选 → 逐项核对（可改可删）→ 确认才入事实层；**拒收零副作用**。
- **手工永远可及但收敛**：统一收在卡片「⋯ 更多」；每页显式编辑 ≤1；表单 ≤6 字段；数字用键盘组件。
- **删除 = 更正**：只新增版本；界面语言"改这一条"；全站无"不可恢复"。
- **回首页一步**：二级页返回 / 顶栏品牌 / 完成 Toast 内嵌「回到看板」。
- **本项目特有**：症状（痒/累）只能患者自己填，**AI 不代填、不估算分数**；判定类（应答/分级/筛查结论）**全部不做 AI 通道**。

## 二、场景路径表（S01–S16，P0 全量）

> 入口文案与看板卡片名**逐字一致**（IP3）。看板四张卡：`今天怎么样` / `接下来` / `最近变化` / `我的问题`。

| ID | 场景 | 入口（逐字） | 步骤（AI=默认 / 手=收敛） | 产物 | 回首页 | 失败恢复 |

| S08 | 甲状腺 | `screening/甲状腺`→「⋯ 更多」 | 同上（TSH/FT4 + 用药） | 筛查记录 +1 | 二级返回 | 同上 |
| S09 | 胃镜 | `screening/食管胃镜`→「⋯ 更多」 | 同上（日期 + 结果原文） | 筛查记录 +1，显示「距上次 N 个月」 | 二级返回 | 无记录 → 显示参考间隔并标来源 |
| S10 | 多久查一次 | 看板「接下来」→「看复查节奏」 | 纯查看（起点 + k×间隔）；手＝设置起点日期（1 字段） | 参考节点 2 个 | 二级返回 | 起点未设 → 引导设确诊日或用药起始日 |
| S11 | 门诊 8 分钟 | 看板「我的问题」→「整理复诊问题」 | AI＝对话"帮我理一下要问的"→候选问题条；手＝勾选已有 + 新写（≤6） | 问题清单 5 条 + `records/导出` 快照 | 完成 Toast | 不想写 → 给 3 条结构引导句 |
| S12 | 相册里的单子 | `records/导入`→「选文件」 | AI＝PDF/照片→MinerU 候选→逐项核对；手＝「⋯ 更多」手工补一条（≤6 字段） | 化验记录 +N（确认几条加几条） | 完成 Toast | 解析失败/无 Token → 手工补录；拒收全部 → 事实层零变化 |
| S13 | 找试验 | `trials/检索`→ 搜索框 | AI＝对话"帮我找 PBC 的试验"→检索参数候选；手＝关键词 + 地区 | 结果列表 + 收藏 | 二级返回 | 无结果 → 显示该来源覆盖声明，不写"不存在" |

| S15 | 带给医生 | 看板「我的问题」→「导出给医生」 | 纯生成；手＝选时间窗 | 真实文件（含数据截止日） | 完成 Toast | 私密项被过滤；无数据 → 生成"暂无记录"快照 |
| S16 | 半年变化 | 看板「最近变化」 | 纯查看 | 三条结论位 | — | 只有一次记录 → 只显示"较上次：无" |

**覆盖自检（IP2 双向）**：①16 条路径覆盖全部 16 个 P0 场景；②30 个 `(view,sub)` 中被 ≥1 条路径经过的：
S01→labs/指标卡、S02/S03→symptoms/今天的痒·影响与睡眠·我的记录、S04→symptoms/今天的累、S05→treatment/当前用药、
S06→treatment/换线记录、S07–S09→screening/骨骼·甲状腺·食管胃镜、S10→followup/节奏卡、S11→followup/就诊准备、
S12→records/导入、S13→trials/检索、S15→records/导出、S16→dashboard/最近变化；
**其余页签由"线内浏览路径"认领**（每线一条：`labs/一图秀`·`labs/分级说明`、`basics/诊断与抗体`·`纤维化与影像`·`合并症档案`、
`treatment/副作用`、`screening/脂溶性维生素`·`肝影像与 HCC 监测`、`followup/待办与问题`、`records/原件`、
`trials/收藏`·`来源说明`、`dashboard/今日概览`·`接下来`）→ **孤儿页 = 0**。G2 由无头脚本穷举复核。

## 三、CRUD 双通道矩阵

| 实体 | AI 协助（默认） | 手工（收敛 / ≤6 字段） | 说明与红线 |
| --- | --- | --- | --- |
| 化验记录 `lab_result` | PDF/照片 → 候选（项目名+值+单位+参考范围+日期） | 「⋯ 更多」补一条：日期/项目/值/单位/下限/上限（6） | 只抄写不判断；单位认不出留空；缺上限标「需参考上限」；结论照抄原文 |
| 症状记录 `symptom_log` | 对话 → 候选（痒分/累档/夜间/抓痕） | 滑条 + 三档 + 勾选（3–4） | **AI 不估算分数**：候选里的分数必须来自用户原话，缺则留空 |
| 用药 `medication` | 对话 → 候选（药名/剂量原文/频次） | 药名/剂量/频次（3） | 药名标「获批状态未核实」；UDCA 剂量按用户抄录的体重与片数存原文 |
| 漏服 `adherence` | 对话"今天忘了"→候选 | 一键（时段） | 只记录，不评判依从性 |
| 换线 `regimen_change` | 对话 → 候选（医生原话 + 日期） | 原文/日期（2） | **不写应答判定**；不改写医生原话 |
| 筛查记录 `screening_record` | 拍报告 → 候选（日期/部位/结果原文） | 日期/类型/结果（3） | 不判读 T 值/分级；不给补钙或替代治疗建议 |
| 就诊问题 `question` | 对话 → 候选问题条 | 勾选 + 新写（≤6） | 不代写医学结论句；只给结构引导 |
| 原件 `document` | 选文件 → 存原件 + 触发解析 | 选文件（1） | 显式告知"原件会离开本机"；Token 只进本地密钥文件 |
| 试验收藏 `trial_bookmark` | 对话 → 候选（从检索结果选） | 结果卡「收藏」 | 标「登记状态，未核实」；不判断入组资格 |
| 档案字段 `profile` | 对话 → 候选（诊断日期/抗体状态/检查方式） | 逐项下拉（≤6） | 抗体三态：阳性/阴性/**未检测**；不判分期 |
