# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：原发性胆汁性胆管炎（PBC）确诊患者本人；照护者可选

场景：长期 UDCA 治疗与 3-6 个月一次的生化随访中，患者自己说不清“现在算不算控制住”、也攒不齐历年化验与筛查记录

核心流程：
1. 导入或录入最近一次肝功能化验单（ALP/GGT/TBil 等）
2. 在指标页看到历年生化序列与相对参考上限的对照
3. 把乏力与瘙痒按天记成表达面，与同日指标并列
4. 从随访节奏卡生成就诊问题清单，导出带走的档案

完成结果：一次门诊前，患者能导出含最近两次生化、治疗与副作用记录、并发症筛查状态与 5 个问题的资料

初始布局选择：business-first
