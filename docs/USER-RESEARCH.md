## 2. 反假设（本轮特意没有做的东西，等访谈证伪/证实）

- **"患者需要看懂应答标准"**：可能相反——患者只想看到"这次的数和上次比"，不想看巴黎/巴塞罗那标准。
  因此本仓把标准放"分级说明"折叠层，**默认不展示判定口径**。
- **"患者想自己算分数（GLOBE/UK-PBC）"**：判断类工具，且属医生口径 → **不做**，只在说明里写"这类评分由医生使用"。

## 3. 方法与环境限制（如实记录）

- `web_search` 工具在本机无凭据，不可用；Bing 网页抓取返回与查询无关结果（本地化重定向污染）。
- 因此**没有做任何社群文本采集**，也没有引用任何患者论坛原话。
- 所有界面文案中的"患者原话"一律标注 `改写句（假设，未访谈）`，不得当作引语引用。
