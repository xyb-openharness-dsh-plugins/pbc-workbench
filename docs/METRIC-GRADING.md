# 指标分级口径 · PBC

> 依据 starter `docs/23-METRIC-GRADING-AND-ALERTS.md`。**分级是"对照"不是诊断**；
> 本仓唯一分级标准 = CTCAE v5.0（`assets/reference/ctcae/CTCAE_v5.0_Quick_Reference_5x7.pdf`），阈值表只存在于 `dsh/ctcae.js` 一份。

## 1. 启用清单（本癌种）

| 指标 | 类型 | 启用 | 理由 |
| --- | --- | --- | --- |
| ALP | ×ULN | ✅ | PBC 的核心生化项；分级必须用该化验单自带上限 |
| GGT | ×ULN | ✅ | 与 ALP 同源，胆汁淤积的并列项 |
| ALT / AST | ×ULN | ✅ | 合并肝细胞损伤时并列 |
| 总胆红素 | ×ULN | ✅ | 疾病进展与预后的关键项（只对照，不解释） |
| 白蛋白 | 绝对（g/L） | ✅ | 肝合成功能；CTCAE 有数值界限 |
| 血小板 | 绝对（10⁹/L） | ✅ | 门脉高压线索；只对照，不推断 |
| 血红蛋白 / 白细胞 / 中性粒细胞 | 绝对 | ✅ | 通用血象（二线药与合并症情境） |
| 肌酐 | ×ULN | ✅ | 用药安全上下文 |
| **瘙痒（pruritus）** | 自评 0–10 | ⛔ **不套 CTCAE** | CTCAE 瘙痒分级只有"轻度/中度/重度"描述，**无绝对数值界限**；按 23 号只启用有数值界限的项。本仓改为**患者自评 0–10 滑条**（表达面），界面不出现"N 级"徽章 |
| **乏力（fatigue）** | 三档 | ⛔ **不套 CTCAE** | 同上；只记"能不能完成日常"三档，属表达面 |
| GLOBE / UK-PBC / 巴黎 / 巴塞罗那评分 | 判定 | ⛔ **不做** | 属医生判定工具；本仓不计算、不引用 |

## 2. 两类指标两套处理（不许混用）

| 类型 | 规则 |
| --- | --- |
| **绝对阈值型**（WBC/ANC/Hb/PLT/白蛋白） | 标准给数值界限；缺个人参考值时可用成人通用下限**近似**，结果带 `approx: true`，界面写「按通用下限」 |
| **×ULN 型**（ALP/GGT/ALT/AST/TBil/肌酐） | **必须用这次化验单自带的 `ref_high`**；没有就返回 `needsUln` + 虚线徽章「需参考上限」，**绝不用通用上限凑倍数** |

一句话记法：**下限可以借，上限不能借。**

## 3. 界面三种"没有级别"必须可区分

| 状态 | 形态 | 触发 |
| --- | --- | --- |
| 正常 | 无徽章 | 在范围内 |
| 缺上限 | **虚线**徽章「需参考上限」 | ×ULN 型且 `ref_high` 为空 |
| 单位错 | **虚线**徽章「单位待确认」 | 如肌酐填成 mg/dL 却按 µmol/L 记录 |

## 4. 边界单测（写进 `test/ctcae.test.mjs`）

1. 缺 `ref_high` → `needsUln`，**不给任何级别**。
2. 整除不等于越界：上限 40、值 120 → `ratio = 3.0` → 1 级；120.1 → 2 级（两个点都要钉）。
3. 三处登记一致（指南未接入时该断言 skip 并写明原因，不留假绿）。
4. 瘙痒/乏力输入不产生任何 `grade` 字段（断言读模型无该键）。
5. `Number(null) === 0` 陷阱：`ref_high = null` 不得被当作 0。

## 5. 提醒边界

- 提醒**只来自用户自己的记录或日期**（如"距上次复查 7 个月"），不来自医学阈值。
- 首页"表达面 / 指标面"两列并置由读模型算 `paired` / `labsOnly`；**只有一侧时不弹提醒**。
