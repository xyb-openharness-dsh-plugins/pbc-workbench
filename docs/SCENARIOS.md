# 场景清单 · PBC（S01–S16）

> **证据等级声明**：本轮 0 访谈（见 USER-RESEARCH §0）。下表「患者原话」全部是**改写句（假设，未访谈）**，
> 由疾病轴推导，不是一手引语；不得当作真实患者发言引用。拿到访谈后逐条替换并升版本号。
> 每条三段：**患者原话（改写假设）/ 页面接住（view·sub·卡）/ 明确不做什么**。

## S01 化验单上的箭头

- **原话（改写·假设）**："ALP 后面一个箭头，医生只说'还行'，我不知道到底差多少。"
- **接住**：`labs·指标卡` → ALP 卡正面：本次值 / 单位 / 这张单子的参考上限 / 较前次差值 / 日期 / 来源；
  背面：为什么这样对照 + 参考上限出处（或"这张单子没印上限"）。
- **不做**：不写"偏高/偏低/严重"；不推断原因；不给复查建议；缺上限时只显示「需参考上限」徽章。

## S02 说控制住了，可我还是痒

- **原话（改写·假设）**："上次医生说指标控制住了，可我痒得还是睡不着，是不是他没当回事？"
- **接住**：`symptoms·我的记录` → 同日两列并置：左「你的记录（痒 7/10、夜间加重）」右「同日指标（ALP 1.4×ULN）」；
  只并列，中间不写连接词。
- **不做**：不写"这说明…"，不解释症状与指标的因果关系；不评估医生判断。

## S03 夜里痒到抓破

- **原话（改写·假设）**："越到晚上越痒，抓得腿上全是印子，白天还好。"
- **接住**：`symptoms·影响与睡眠` → 夜间加重勾选、抓痕/皮肤破损勾选、睡眠被打断次数（0–3+）。
- **不做**：不给瘙痒分级量表结论（如 5-D itch 评分属研究工具，本仓不代填、不算分）；不推荐止痒药。

## S04 累到上不了班

- **原话（改写·假设）**："不是困，是整个人没电，走两层楼要歇。"
- **接住**：`symptoms·今天的累` → 三档单选（能完成日常 / 勉强完成 / 做不了）＋ 一句自由描述 ＋ 时长。
- **不做**：不写"这是乏力还是抑郁"；不换算成任何评分；不设"该休息"阈值。

## S05 又漏了一次药

- **原话（改写·假设）**："早上赶着出门，晚上才想起来没吃，要不要补？"
- **接住**：`treatment·当前用药` → 记「今天漏服」按钮 + 漏服次数月视图；药品名与剂量来自用户抄录的处方。
- **不做**：不回答"要不要补服"；不推算血药浓度；不评判依从性好坏（只记录）。

## S06 医生说要换二线

- **原话（改写·假设）**："说 UDCA 效果不够，要加别的药，我连名字都没记住。"
- **接住**：`treatment·换线记录` → 记「医生提到的方案原文」＋日期＋当时的问题；状态标"待我确认理解"。
- **不做**：不写"应答不足"结论；不比较药物优劣；不写适应证与剂量建议；药名一律标「获批状态未核实」。

## S07 骨密度那张纸

- **原话（改写·假设）**："骨密度报告一堆 T 值，医生说有点低，让我补钙，我没听懂低到哪。"
- **接住**：`screening·骨骼` → 检查日期 / 部位 / 报告原文摘录 / 是否已被告知下一步（是·否·没说）。
- **不做**：不判读 T 值分级（-1/-2.5 的界限属医生口径）；不给补钙剂量。

## S08 甲状腺是另一个科

- **原话（改写·假设）**："内分泌科说我甲减，肝病科不知道，两边报告我自己都找不到。"
- **接住**：`screening·甲状腺` → TSH/FT4 记录 ＋ 用药（如左甲状腺素）独立小节，标"另一科开的"。
- **不做**：不判断甲减与 PBC 的关系；不给替代治疗调整建议。

## S09 要不要做胃镜

- **原话（改写·假设）**："医生提过查食管静脉，我怕难受一直没去，也不知道多久该查一次。"
- **接住**：`screening·食管胃镜` → 上次检查日期 / 结果原文 / 「距上次 N 个月」＋参考间隔（标来源与"仅供参考"）。
- **不做**：不写"你该去查了"；不做出血风险分级；不替用户排检查。

## S10 到底多久查一次

- **原话（改写·假设）**："有时三个月，有时半年，我问为什么，医生说他看着办。"
- **接住**：`followup·节奏卡` → 起点（确诊日/开始用药日）＋ k×间隔的参考节点；一屏声明「±30 天是工作台显示带宽，不是指南内容」。
- **不做**：不发提醒、不弹通知；不按分期调整（分期未记录时写"未按分期调整"）。

## S11 门诊 8 分钟

- **原话（改写·假设）**："排队两小时，进去五分钟，出来才想起要问的全忘了。"
- **接住**：`followup·就诊准备` → 从待办/问题池勾选 5 条 → 生成清单 → `records·导出` 出快照。
- **不做**：不替用户写医学问题（只提供结构性引导句，如"我想问：这次的 ALP 和上次比…"）。

## S12 化验单都在相册里

- **原话（改写·假设）**："每次的单子拍完就沉底了，找上个月的得翻半天。"
- **接住**：`records·导入` → 选 PDF/照片 → 显式告知"原件会上传到云端解析" → 候选逐项核对 → 确认入事实层。
- **不做**：不自动入库；单位认不出留空；不猜数值；拒收候选零副作用。

## S13 有没有能参加的研究

- **原话（改写·假设）**："这病有没有新药试验？我住的省有没有？"
- **接住**：`trials·检索` → 关键词/地区检索 → 结果卡片标来源与「登记状态，未核实」。
- **不做**：不判断是否符合入组条件；不承诺"可以参加"；无结果时给该来源的覆盖声明。

## S14 家里人要不要查

- **原话（改写·假设）**："我妈也有肝病，这病会不会传给孩子？"
- **接住**：`settings·关于` 里一句客观说明＋「问医生」入口；**不设家属筛查功能线**。
- **不做**：不做遗传风险分级、不给筛查建议、不写"家属应该查"。

## S15 把资料带给医生

- **原话（改写·假设）**："我想把最近半年的化验和我在吃的药打出来，医生看得快一点。"
- **接住**：`records·导出` → 生成快照（含生成时间、数据截止日、"此后新增记录未包含"标记）→ 真实文件下载。
- **不做**：不把私密标记内容放进导出（逐项过滤）；不生成"病情摘要结论"，只并列事实。

## S16 这半年到底变了什么

- **原话（改写·假设）**："我只记得最近一次，前面几次什么趋势完全没印象。"
- **接住**：`dashboard·最近变化` → 三条最小结论位（最近一次、较上次、距下次参考节点），点进去看一图秀。
- **不做**：不写"恶化/好转"；不预测；不排名。
