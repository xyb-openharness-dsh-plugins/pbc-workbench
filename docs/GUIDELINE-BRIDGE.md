| # | 问题 | 答案 | 结论 |

| Q1 | 有权威且带页码的中文指南吗 | 期望来源：《原发性胆汁性胆管炎诊断和治疗指南（2021）》，中华医学会肝病学分会 | 存在性**未核实**（无原件，也无可用检索通道） |

## 3. 补做条件（拿到原件后的动作清单）

1. 原件入库 `guidebooks/pbc-2021/pbc-2021.pdf`，登记 `manifest.json`（org/version/published/pages/sha256/来源/是否 OCR/允许用途），
   且 **`guidebooks/` 不进 `package.json` 的 `files`**（`npm pack` 要能证明没进包）。
2. `assets/reference/guideline/refs.json` + `cadence.json`（只存页码、表号、≤200 字摘录、notes；**必须随包分发**）。
3. 三处登记（manifest / refs / cadence）的 `id/version/published/sha256` 逐字一致 + 一条单测钉住。
4. 界面两段式：`指南这里写的是：…（版本 · Pxxx）` / `你的记录是：…`，中间不合成判断、不出现"所以/因此/你需要"。
5. 补 G2 纯函数（`addMonths` 月末夹取、`checkpoints`、`applicableChecks`）与 G3 阈值（如有独立于 CTCAE 的阈值，双标准并列）。
