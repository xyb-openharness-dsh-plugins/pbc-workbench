## 1. 建轴（十条疾病轴，逐条问"本癌种有什么不一样"）

| 轴 | 本癌种的不同 | 是否落成功能 |
| --- | --- | --- |

| 分型分期 | **不做分期**；纤维化只有检查方式与原文（弹性/影像/病理不可互算） | ✅ `basics/纤维化与影像` |
| 治疗路径与切换 | 长期单一用药（UDCA）+ 可能的二线加药；**"换线"是低频但高焦虑事件** | ✅ `treatment/换线记录`（只存医生原话） |
| 症状与功能 | 瘙痒（夜间加重、抓痕）与乏力（能不能完成日常）是主要负担，**无客观检查替代** | ✅ 独立一级 `痒与累`（4 二级） |
| 营养与进食 | 无特异性进食障碍（与胃癌/食管癌不同）→ 只保留脂溶性维生素 | ✅ `screening/脂溶性维生素` |
| 心理与家庭 | 不做独立心理线；不做家系筛查（非传染性、无原件可核） | ⛔ 明确不做（DIFF-MATRIX L7） |
| 复查随访 | 3–6 个月生化；叠骨密度/甲功/胃镜/肝影像，**多科室各自节奏** | ✅ `复查节奏` + `并发症筛查`（5 二级） |
| 第二原发与并发症 | 肝硬化并发症（静脉曲张）、骨质疏松、甲状腺、脂溶性维生素缺乏 | ✅ `screening` 按系统分节 |
| 临床研究 | 在线四通道；离线语料未覆盖 | ✅ `临床研究`（3 二级，标未核实） |
| 费用与资源 | 长期单药，费用压力弱于肿瘤；本轮不做独立线 | ⛔ 明确不做 |
